Dicoogle

How does this open source repository relate to critical infrastructure and healthcare?

This project is a Picture Archiving and Communication System (PACS) that manages DICOM images and metadata. DICOM is a critical imaging and metadata format in the healthcare industry.

What would vulnerabilities in this repository mean for critical infra & healthcare?

This system would have access to extremely sensitive patient PII, images and data. Vulnerabilities in this software could be catastrophic for a) information disclosure and b) data availability and integrity.
