# What design decisions were considered for this challenge?

Most commons-compress deltas are separated into individual
challenges to offer focused, simpler challenges compared to
other repos where multiple vulnerabilities are bundled into
a single challenge.

# Why this set of vulnerabilities?

The vulnerabilities are separated because they conflict with each other when combined.

# Delta vs Full and why?

Delta scan challenge because commons-compress appeared in earlier
Finals rounds, so a full repo scan is not appropriate.
