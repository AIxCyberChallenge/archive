Whistle Data Transformation Language

How does this open source repository relate to critical infrastructure and healthcare?

This repo offers a "mapping language for converting complex, nested data from one schema to another". The primary focus is on healthcare data, but this transformation language can be used on any complex nested data.

What would vulnerabilities in this repository mean for critical infra & healthcare?

Vulnerabilities in this repo would be disastrous for data integrity and data reliability.
