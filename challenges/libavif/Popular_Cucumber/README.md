# What design decisions were considered for this challenge?
This challenge tests whether CRSes can identify existing vulnerabilities in an organic codebase.

# Why this set of vulnerabilities?
This challenge includes zero synthetic vulnerabilities.

# Delta vs Full and why?
This challenge is a delta scan challenge wrapping the release of libavif v1.3.0.
The delta contains the differences between versions v1.2.0 and v1.3.0.
